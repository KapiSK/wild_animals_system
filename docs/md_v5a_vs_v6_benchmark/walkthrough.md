# MegaDetector V5a vs V6 ベンチマーク構築の完了報告

ご要望に基づき、Linuxサーバー向けのGPU対応自動セットアップスクリプト、および「定量的・定性的な比較分析」を兼ね備えたベンチマーク環境の構築が完了しました。

## 実装内容のサマリー

### 1. 比較用ベンチマークスクリプト (`ai_ex/benchmark_v5a_vs_v6_matrix.py`)
V5a と V6 を同時に走らせ、純粋に「動物を見つけたか・見落としたか」の**混同行列（Confusion Matrix）**を高速に算出するプログラムを作成しました。
*   **設定の簡易化**: スクリプト上部（14行目付近）の `INPUT_DIR` などを書き換えるだけで、比較したいフォルダや信頼度閾値（V5a: `0.25`, V6: `0.30` など）を自由に変更できます。
*   **食い違い（Mismatch）の効率的分析**: すべての画像ではなく、**「V5aとV6で検知結果が食い違った画像」についてのみ、バウンディングボックスを描画した左右結合画像（比較画像）**を生成します。これにより、数万枚のデータセットでもディスク容量を圧迫せずにエッジケースを確認できます。
*   **各種レポート出力**:
    *   `results_benchmark/confusion_matrix.png` : 分析用ヒートマップ画像
    *   `results_benchmark/mismatch_list.csv` : 結果が食い違ったファイルのリスト（なぜ間違えたかの内訳）
    *   `results_benchmark/benchmark_full_report.csv` : 実行時間を含む全データの詳細ログ

### 2. Linux用環境構築スクリプト (`ai_ex/setup_benchmark_linux.sh`)
GPUサーバーへ持っていき、コマンドを一発叩くだけで本番環境のテスト準備が整うスクリプトです。
*   Pythonの仮想環境（venv）の作成
*   CUDA対応（デフォルトではcu118）のPyTorchインストール
*   両モデルに必要な依存ライブラリ群の一括インストール
*   クラウド用V5aモデル (`md_v5a.0.0.pt`) が存在しない場合の自動ダウンロード機能

## テスト結果（ローカルでの実行）
現在ローカルにある3枚の画像セットでテストランを行いました。

```
========================================
  Confusion Matrix (混同行列)
  ※ V6を「擬似正解」とした場合
========================================
               [V5a 予測]
               検知(1)   検知なし(0)
[V6 正解]  (1)  0         2        (FN)
           (0)  0        (FP) 1       
========================================
 - True Positives (両方検知)  : 0
 - True Negatives (両方無視)  : 1
 - False Positives(V5a過検出) : 0 -> V5aがノイズを誤認した可能性
 - False Negatives(V5a取こぼし): 2 -> V5aが動物を見落とした可能性
 - Mismatch 合計              : 2 枚
========================================
```
このテストにより、**V5aは「False Negative（V6なら拾えていた動物を見落とす）」を2件起こしている**ことが定量的に示されました。
（この2件の詳しい様子は、自動生成された比較画像 `ai_ex/results_benchmark/mismatches/` 内で確認可能です）

## 今後のサーバーでの実行手順
1. 本プロジェクトごとLinuxサーバーへ配置します。
2. サーバー上で `cd ai_ex` で移動後、`bash setup_benchmark_linux.sh` を実行します。
3. `source venv/bin/activate` で仮想環境に入り、`python benchmark_v5a_vs_v6_matrix.py` を実行するだけで、サーバーの大規模データセット上で検証が開始されます。
