# 論文修正の実装計画 (Implementation Plan)

## 修正内容

### 1. まえがきの課題強化と貢献の明記
- 導入・運用コストの問題の段落に、消費電力と大型バッテリーによる設置場所の制限・機材コスト増大の課題を追加する。
- 1章末尾に、本研究の貢献（機能分離による初期コスト低減、回線集約による運用コスト削減、二段階AIによる空撮影削減と高精度通知）を文章で追加する（箇条書きは使用しない）。

### 2. 関連研究における研究ギャップの強調
- 2章末尾に、既存研究の到達点と本研究の立ち位置（低消費電力カメラ・回線集約・AIの活用によるシステム）を接続する総括の段落を追加する。
- ※段落ごとのリード文による分類は行わない。

### 3. 曖昧な用語の定量的定義
- 3章冒頭に、「低コスト」の定義（初期導入・運用の両面）と、「広域監視網」の定量的定義（半径100〜200mのWLAN通信範囲で数ヘクタールの農地を網羅）を追記する。
