### 4. 「提案システム」の執筆

- **システム構成**:
  - エッジカメラ (ESP32): 省電力撮影、即時送信
  - エッジサーバ (Raspberry Pi): AI推論 (YOLO)、フィルタリング
  - 外部サーバ: 通知
- **処理フロー**:
  - 動体検知 → 撮影 → 送信 → 推論 → 通知の流れを記述しました。

### 5. 「実装」の執筆

- **エッジカメラ**: XIAO ESP32S3 Sense, Deep Sleep, UXGA撮影
- **エッジサーバ**: Raspberry Pi 4, Flask, YOLOv8n (Nanoモデル)
- **外部サーバ**: Flask, データ蓄積, メール通知
