### 1. タイトルの更新

- **和文タイトル**: 鳥獣害対策のための複数台カメラを用いた低コスト通信型警戒システムの開発
- **英文タイトル**: Development of a Low-Cost Communication-Based Monitoring System Using Multiple Cameras for Wildlife Damage Control

### 2. 「まえがき」の執筆

- 野生動物被害の現状と課題（誤検知、コスト）を整理しました。
- 本研究の目的（低コスト、分散処理、リアルタイム通知）を明確化しました。

### 3. 「提案システム」の執筆

- **システム構成**:
  - エッジカメラ (ESP32): 省電力撮影、即時送信
  - エッジサーバ (Raspberry Pi): AI推論 (YOLO)、フィルタリング
  - 外部サーバ: 通知、蓄積
- **処理フロー**:
  - 動体検知 → 撮影 → 送信 → 推論 → 通知の流れを記述しました。
