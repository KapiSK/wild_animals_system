# AI Context for Antigravity IDE (Seamless Sync)

このファイルは、2台のPC間でAntigravity IDEの作業コンテキスト（会話の文脈）をシームレスに引き継ぐための状態管理ファイルです。Gitを経由して同期されるため、別のPCで作業を再開する際の情報源となります。

**【AIへの絶対指示】**
新たな環境（別のPC等）で会話が開始された際、ユーザーから「作業を再開して」等の指示があった場合は、**必ず最初にこのファイルを読み込み（`view_file`）、現在の進捗と直近のタスクを把握してください。**
また、作業が完了・中断する際は、必ずこのファイルの `Current Status` と `Next Steps` を最新の状態に更新してください。

## Project: IEICE Paper Draft (wild_animals)

### Current Status (最終更新: 2026-06-23)

- 「まえがき」の課題・貢献の論理強化、関連研究のギャップ明記、3章の「低コスト」「広域」の定量的定義を `main.tex` に反映し、コンパイル（PDF生成）を完了した。
- ユーザーの「メモ」ファイルに基づき、**「まえがき」の根拠（引用文献）が不足している箇所**（カメラトラップの有用性、空撮影の頻度、通信・電源のコスト課題）の特定と、必要な論文情報の要件整理を完了した。
- 現状は、**ユーザーからの追加の引用文献（BibTeX等）の提供を待っている状態**である。

### Next Steps (次に行うべき作業)

1. ユーザーから追加の文献情報が提示されたら、`refs.bib`（または該当のbibファイル）に追加する。
2. 提示された文献をもとに、`main.tex` の「まえがき」の該当箇所（メモで指摘された箇所）に引用（`\cite{}`）を挿入する。
3. その際、「SDカード回収の遅れ」と「深層学習による労力削減」の論理のねじれを解消するよう文章を微調整する。
4. `uplatex` -> `upbibtex` -> `uplatex` -> `dvipdfmx` の手順でコンパイルし、PDFを確認する。
5. 作業完了後、`task.md` およびこの `ai_context.md` を更新する。

### Development Guidelines (引き継ぎ用メモ)

- 言語はすべて日本語を使用する。
- ドキュメント類（`task.md`, `implementation_plan.md`, `walkthrough.md`, `ai_context.md`）は `docs/ieice_paper_draft/` 配下に維持し、Gitで管理する。
- IEICEの和文論文のため、必ず `uplatex` 環境を用いてコンパイルする。
