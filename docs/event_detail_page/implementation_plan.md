# Event Detail Page Implementation Plan

## 1. 目的 (Objective)
ギャラリー画面から画像をクリックした際のモーダル表示（拡大表示）は維持しつつ、イベント（サイクル）単位でのより詳細な情報（関連する全ての画像、動画、検知メタデータ等）を確認するための専用ページを新たに作成します。
また、ギャラリー画面の各サイクルの折りたたみ領域内に、その詳細ページへ遷移するためのボタンを配置します。

## 2. 変更内容 (Proposed Changes)

### 2.1 イベント詳細ページの新規作成
- **対象ファイル**: `server.py`
- **実装内容**:
  - 新しいエンドポイント `@app.get("/event/{camera_id}/{event_id}", response_class=HTMLResponse)` を作成します。
  - 先ほど削除した旧イベント詳細ページのデザインをベースに、特定の画像パス起点ではなく「イベント単位」で情報が集約される画面を構築します。
  - **表示内容**:
    - 対象イベントの全ての「処理済み画像 (With box)」と「元画像 (No box)」のサムネイル。
    - クリック時のメイン画像切り替え機能。
    - イベントに関連する動画 (`<video>` 要素)。
    - メタデータ（検知ラベル、時間、カメラID等）。

### 2.2 ギャラリー画面へのボタン追加
- **対象ファイル**: `server.py` 内のギャラリーHTML生成ロジック (`renderGallery`)
- **実装内容**:
  - サイクルごとの折りたたみヘッダー部（またはその直下）に、「詳細情報を見る (View Event Details)」というリンクボタンを配置します。
  - このボタンをクリックすると、上記で作成した `/event/{camera_id}/{cycle_id}` ページに遷移します。

## 3. 確認事項 (Open Questions / User Review)
> [!IMPORTANT]
> 1. 新しい詳細ページのURLは `/event/カメラ名/サイクルID` （例: `/event/cam1/20260519100000_123`）となります。この設計でよろしいでしょうか？
> 2. 詳細画面での画像クリック時も、（画面遷移ではなく）モーダル拡大されるようにした方がよろしいでしょうか？

## 4. 確認手順 (Verification Plan)
1. ギャラリー一覧画面に「詳細を見る」ボタンが表示されていることを確認する。
2. ボタンをクリックして詳細画面に遷移することを確認する。
3. 詳細画面で、そのイベントに紐づく画像、動画、メタデータが正しく表示されることを確認する。
