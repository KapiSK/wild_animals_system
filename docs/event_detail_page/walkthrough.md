# Event Detail Page Walkthrough

## 実装の概要
ギャラリー一覧画面にサイクル（イベント）ごとの「詳細を見る」ボタンを追加し、専用の詳細画面(`/event/{camera_id}/{event_id}`)を復活・再構築しました。

## 変更内容とポイント

### 1. イベント詳細ページの構築
- **新しいエンドポイント**: `@app.get("/event/{camera_id}/{event_id}")` を作成。特定の画像ではなく、イベント全体の情報をロードする設計に変更しました。
- **表示項目の整理**:
  - 対象サイクルのカメラID、イベントID、検知時刻、検知ラベルといった「メタデータ」を上部に表示。
  - サイクルに関連する「動画」があれば再生プレイヤーを表示。
  - ボックスあり（Processed）と ボックスなし（Raw）の画像を、見比べやすいよう左右の2列（モバイルでは縦積み）で並べて表示。
- **画像拡大（モーダル）**:
  - 詳細画面内の画像をクリックした際も、一覧画面と同じく「その場でオーバーレイ拡大表示」されるように実装を統一しました。

### 2. ギャラリー画面からの導線追加
- ギャラリー画面（カメラ別表示・全体表示の両方）の「サイクルの折りたたみを開いた中（動画のすぐ上）」に、**「View Event Details ↗」** というボタンを追加しました。
- 画像を軽く確認したい時は一覧画面のクリックで拡大し、AIの全推論結果や生画像と比較したい時はこのボタンから詳細ページへ飛ぶ、という使い分けが可能になっています。

## 確認のお願い
サーバーを再起動またはリロードしていただき、ギャラリー画面のサイクルを開いてみてください。
「View Event Details」ボタンが配置されており、クリックするとイベントの全データが集約された詳細ページが表示されるはずです。
