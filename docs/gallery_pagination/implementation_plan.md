# Gallery Pagination and Video Integration Plan

## 1. 目的 (Objective)
1. 全体表示（Flatモード）の各サイクルの折りたたみ領域内に、イベントの動画を配置します。
2. ギャラリー一覧のパフォーマンスを保つため、画像が大量に蓄積されてもブラウザが重くならない「要素の差し替え方式」のページネーション（ページ切り替え）機能を導入します。

## 2. 変更内容 (Proposed Changes)

### 2.1 全体表示（Flatモード）への動画配置
- **対象ファイル**: `server.py` 内のJS (`renderGallery` の Flatモード描画部)
- **実装内容**: `flat-cycle-content` の内部に、カメラ別（Grouped）モードと同様の動画プレイヤー生成ロジックを追加します。

### 2.2 独立したページネーションと件数切り替え (10 / 25 / 50)
API側での強制的な「最新500件」の制限を外し、フロントエンド側で各表示モードに応じたページネーションを実装します。要素を追加するのではなく「古いものを消して新しいものを描画する（差し替え）」ため、どれだけページをめくっても絶対に重くなりません。

- **対象ファイル**: `server.py` (HTML/JS)
- **状態管理 (JS)**:
  - 全体表示用: `flatPagination = { page: 1, limit: 25 }`
  - カメラ別表示用: 各カメラごとに状態を保持。 `groupedPagination[cameraName] = { page: 1, limit: 10 }` （デフォルト10件）
- **UI追加と描画ロジック**:
  - **全体表示（Flatモード）**: 画面上部にグローバルなページネーションコントロール（表示件数のプルダウン、前へ、次へ）を配置。
  - **カメラ別表示（Groupedモード）**: 各カメラ（CAM: xxx）の折りたたみの中に、**そのカメラ専用のページネーションコントロール**（表示件数 10/25/50 プルダウン、前へ、次へ）を配置。
  - 切り替え操作を行うと、該当する部分のHTMLのみを再計算し、DOMを差し替えます。

## 3. 確認事項 (Open Questions / User Review)
> [!IMPORTANT]
> 1. カメラごとの表示件数のデフォルトは「10件」とし、ユーザーがプルダウンで「25 / 50」に変更できる形を想定していますが、デフォルト値に希望はありますか？（最初から25件表示が良い、等）

## 4. 確認手順 (Verification Plan)
1. 全体表示（Flatモード）でサイクルを開いた時、動画プレイヤーが正しく表示されることを確認する。
2. 全体表示でページネーション・件数切り替えが動作することを確認する。
3. カメラ別表示（Groupedモード）で、各カメラごとに独立してページネーション・件数切り替え（10/25/50件）が動作することを確認する。
4. 何度ページを切り替えてもブラウザの動作が重くならないことを確認する。
