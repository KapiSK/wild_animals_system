# Gallery Pagination and Video Integration Walkthrough

## 実装の概要
ギャラリーの全体表示（Flatモード）に動画プレイヤーを追加し、さらに大量の画像データをサクサク閲覧するための「DOM差し替え方式のページネーション」を実装しました。

## 変更内容とポイント

### 1. 全体表示（Flatモード）への動画配置
- これまでカメラ別表示（Groupedモード）にしかなかったインライン動画プレイヤーを、Flatモードの各サイクルの折りたたみ内部（「View Event Details」ボタンの下）にも追加しました。

### 2. 要素の差し替え方式によるページネーション
API側での「最新500件のみ」という強制制限を取り払い、全データを取得した上でフロントエンド（ブラウザ側）でページネーションを行うようにしました。

- **カメラ別表示（Groupedモード）**
  - 各カメラの折りたたみを開いた直下に、そのカメラ専用のページネーションコントロールを配置しました。
  - デフォルトで **10件（10サイクル）** が表示されます。
  - セレクトボックスで「10件 / 25件 / 50件」の切り替えが可能で、「＜ 前へ」「次へ ＞」ボタンでそのカメラの中身だけを入れ替えます。

- **全体表示（Flatモード）**
  - 画像一覧の一番上（フィルターなどの下）に、全体用のページネーションコントロールを配置しました。
  - こちらもデフォルトで **10件** ずつ表示され、すべてのカメラの画像が時系列で混ざった状態でページをめくっていくことができます。

### ブラウザの負荷対策
「もっと見る」ボタンで要素を追加し続ける方式ではなく、**「現在表示されている要素を一度消して、次のページ分だけを描画する（差し替え）」**方式を採用しています。
このため、表示件数を50件にして何十ページめくったとしても、ブラウザのメモリが圧迫されて重くなることはありません。

## 確認のお願い
サーバーを再起動またはリロードしていただき、以下の点をご確認ください。
1. **全体表示（Flat）**: 画面上部のページネーションでページを切り替えられること。折りたたみを開くと動画が表示されること。
2. **カメラ別表示（Grouped）**: 各カメラの折りたたみを開き、専用のページネーションで10/25/50件の切り替えやページ移動ができること。
3. ページを切り替えた際、画面が重くならずにサクサクと画像が入れ替わること。
