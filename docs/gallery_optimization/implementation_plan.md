# Gallery UI Optimization and Modal Integration Plan

## 1. 目的 (Objective)
ギャラリー一覧画面(`/gallery`)の読み込み速度と操作性を向上させるため、以下の改修を行います。
1. **画面遷移の廃止**: 詳細画面(`/event`)への遷移を廃止し、一覧画面内で画像がオーバーレイ（モーダル）表示されるようにします。
2. **パフォーマンス改善**: 画像の遅延読み込み（Lazy Load）、動画のプリロード停止、初期読み込み件数の制限を導入し、ブラウザのフリーズや大量の通信を防ぎます。

## 2. 変更内容 (Proposed Changes)

### 2.1 ギャラリー画面へのオーバーレイ（モーダル）追加
- **対象ファイル**: `server.py` の `@app.get("/gallery")` レスポンス部分。
- **実装内容**:
  - `event_detail` 画面で追加したようなオーバーレイ用のCSSとHTML要素（`<div id="imageOverlay">...</div>`）をギャラリー画面の末尾に追加します。
  - JS関数 `openOverlay(src)` と `closeOverlay()` を追加します。

### 2.2 リンク遷移の無効化と `onclick` の設定
- **対象ファイル**: `server.py` 内のJS関数 `renderImageCard` や `buildEventUrl` 周辺。
- **実装内容**:
  - 画像カードの `onclick` イベントを `window.location.href='...'`（画面遷移）から `openOverlay(this.querySelector('img').src)` に変更します。
  - これにより、一覧画面の画像をクリックするとその場で拡大表示されるようになります。

### 2.3 動画(Video)の一覧表示とプリロード最適化
- **対象ファイル**: `server.py` 内のギャラリーHTML生成ロジック。
- **実装内容**:
  - これまで詳細画面にのみ表示していた `<video>` を、一覧のサイクルセクション内に直接配置します。
  - その際、必ず `preload="none"` を設定し、自動ダウンロードを防ぎます。
  - 動画の `poster` 属性にサイクルの代表画像を指定し、動画が画像のように見えるようにします。

### 2.4 画像の遅延読み込み (Lazy Loading) と件数制限
- **対象ファイル**: `server.py`
- **実装内容**:
  - すべての `<img>` タグに `loading="lazy" decoding="async"` を付与します。
  - フロントエンドに渡す画像リストについて、最新の500件（または特定のサイクル数）に制限してレンダリングの負荷を軽減します。

## 3. 確認事項 (Open Questions / User Review)
> [!IMPORTANT]
> 1. イベント詳細ページ(`/event/...`)は廃止または非推奨となりますが、これに依存している外部へのリンク等はありませんでしょうか？
> 2. 初期表示の制限件数は**「最新の500件の画像」**程度を想定していますが、これでよろしいでしょうか？

## 4. 確認手順 (Verification Plan)
1. サーバーを起動し `/gallery` にアクセスする。
2. ページを開いた際の初期読み込みが高速化されていることを確認する。
3. 画像をクリックすると、画面遷移せずにオーバーレイで拡大表示されることを確認する。
4. オーバーレイの外側をクリックすると閉じることを確認する。
5. サイクル内の動画が自動ダウンロードされず、再生ボタンを押して初めて再生されることを確認する。
