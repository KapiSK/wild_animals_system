# 実験用計測実装計画

この計画は、ユーザーが要求するメトリクスを測定するために、野生動物監視システム（ESP32カメラ、エッジサーバ、外部サーバ）に対して行うコード変更の詳細を記述します。

## 目標

以下の項目の測定を可能にする：

- **エッジカメラ**: サイクル所要時間、通信統計（時間、RSSI）、消費電力状態の可視化。
- **エッジサーバ**: 処理時間、スループット、精度評価ログ、通信削減率。
- **外部サーバ**: 精度評価ログ、ユーザー通知遅延、全体の削減率。

## ユーザーレビュー必須事項
>
> [!IMPORTANT]
> **消費電力の測定**: 本計画では、消費電力を直接測定するためのハードウェア（USB電力計やプロファイラなど）が手元にあることを前提としています。コード側では、特定のモード（撮影、WiFi接続、アップロード）に入ったタイミングでログやLED状態を出力し、電力測定値との照合を容易にする変更を行います。

> [!NOTE]
> **精度の評価**: システムは「真に動物が映っているか」を自動的に知ることはできません。コードは*推論結果*をCSVファイルに記録します。ユーザーは保存された画像を手動で確認し、「真の値」を記録して、精度と削減率を計算する必要があります。

## 変更内容案

### コンポーネント: ESP32カメラ (`esp/camera/camera.ino`)

- **時間計測ログ**:
  - `t_capture_start` (1枚目撮影前) から `t_upload_end` (スリープ直前) までを計測。
  - `t_wifi_duration` (接続開始 -> IP取得) を計測。
  - `t_upload_duration` (アップロード開始 -> 全完了) を計測。
- **信号強度**:
  - アップロード時に `WiFi.RSSI()` をログ出力。
- **出力**:
  - シリアルモニタおよび `esp.log` に構造化された形式で出力（例: `[METRICS] CycleTime=... RSSI=...`）。

### コンポーネント: エッジサーバ (`pi/main.py`)

- **CSVログ出力**:
  - 画像ごとの統計とサイクルごとの統計を記録する `edge_metrics.csv` を作成。
  - カラム: `timestamp, filename, cycle_id, inference_time_ms, is_animal, conf, forwarded`。
- **時間計測**:
  - `process_image` 関数内で `detector.detect` の実行時間を計測。

### コンポーネント: 外部サーバ (`original_server/server.py`)

- **CSVログ出力**:
  - `cloud_metrics.csv` を作成。
  - カラム: `timestamp, filename, cycle_id, inference_time_ms, is_animal, email_sent_time`。
- **時間計測**:
  - MegaDetectorの推論時間を計測。
  - エンドツーエンド遅延: ESP32側との厳密な時刻同期は複雑になるため、ここでは「エッジサーバでの受信 -> メール送信」の部分をサーバ側の制御可能な遅延として計測し、ESP側では「撮影 -> エッジサーバ送信完了」を計測することで、合計時間を算出する方針とします。

## 検証計画

### 自動テスト

- なし（ハードウェア依存のため）。

### 手動検証手順

1. **ESP32メトリクス**:
    - ESP32にファームウェアを書き込む。
    - PIRセンサーを反応させる。
    - シリアルモニタで `[METRICS]` 行が出力されるか確認する。
    - `Capture Cycle Duration` が現実的な値（5〜10秒程度？）か確認する。
2. **エッジサーバ・メトリクス**:
    - `/upload` にテスト画像を送信する。
    - `edge_metrics.csv` が作成され、データが追記されるか確認する。
    - `inference_time_ms` が記録されているか確認する。
3. **外部サーバ・メトリクス**:
    - 外部サーバにテスト画像を送信する。
    - `cloud_metrics.csv` にデータが追記されるか確認する。
    - 「メール送信」ログと時刻が記録されているか確認する。

## 実験手順（ドラフト）

1. **準備**: 全てのログとCSVファイルをクリアする。
2. **実行**:
    - カメラを距離 X メートルに設置する。
    - 動物（または疑似ターゲット）および空のシーンを含む N サイクル（例: 20サイクル）をトリガーする。
3. **データ収集**:
    - `esp.log` をダウンロード（SDカード経由またはアップロード）。
    - Piから `edge_metrics.csv` をダウンロード。
    - 外部サーバから `cloud_metrics.csv` をダウンロード。
4. **分析**:
    - 各時間の平均値を算出。
    - 推論結果 (`is_animal`) と手動確認（正解データ）を突き合わせ、精度と再現率を計算。
