# 統計ページ向けデータ収集機能の実装

将来の統計ページ開発に向けて、カメラ名・気温・日時・動物の種類を CSV ファイルに蓄積する機能の実装が完了しました。

## 変更内容

クラウドサーバの `server.py` の中で、イベント検知の処理（`process_cycle`）が完了したタイミングでデータを保存する処理を追加しました。

### 1. イベントごとの JSON メタデータへの気温の追加
- イベントが発生するごとに作られるメタデータ（`event_metadata`）に、新しく `"temperature"` フィールドを追加しました。
- この値は、Satos などのエッジサーバから送られてきている最新の `telemetry` データから取得しています。

### 2. `statistics.csv` への蓄積
- 処理の最後に、ルートディレクトリの `statistics.csv` に以下の情報をカンマ区切りで追記（アペンド）する処理を追加しました。
  - `timestamp`: 画像の撮影日時（例: `2026/04/09 15:08:49`）
  - `camera_id`: カメラのID
  - `temperature`: 最新の気温（未取得の場合は空欄）
  - `labels`: 検出された動物の種類（例: `person|dog`）
  - `target_count`: 検出された対象物の総数

## 保存形式のイメージ
実際の `statistics.csv` は以下のように記録されていきます。

```csv
timestamp,camera_id,temperature,labels,target_count
2026/04/09 15:08:49,CAM_01,23.5,person|dog,2
2026/04/09 15:15:20,CAM_02,24.0,None,0
```

> [!NOTE]
> エッジ（Piなど）が気温のデータを送信していない場合は、`temperature` の値は空文字になります。

今後はこの `statistics.csv` のデータを読み込むことで、統計ページのグラフなどを容易に作成することができます。
