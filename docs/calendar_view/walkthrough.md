# Calendar View Walkthrough

## 実装の概要
ギャラリーの表示モードに「カレンダー (Calendar)」を追加し、日付ベースで動物や人の検知状況を直感的に確認できる機能を実装しました。

## 変更内容とポイント

### 1. カレンダー表示モードの追加
- ギャラリー上部の「表示形式」セレクトボックスに、第3のモードとして **カレンダー (Calendar)** を追加しました。
- これを選択すると、画像一覧やフィルターが非表示になり、代わりに月間カレンダーが表示されます。

### 2. 日付マスのデザイン
ご要望に合わせ、各マスには「検知件数」と「アイコン」のみを表示するシンプルなデザインを採用しました。
- **件数表示**: その日に検知イベント（画像/動画）があった場合、赤みがかったバッジで「〇件」と表示されます。
- **アイコン化**: 検知されたラベルを自動判別し、絵文字に変換して表示します。
  - `person`, `human` などのラベル → 👤
  - `animal`, `deer`, `bear`, `boar` などのラベル → 🐾
  - それ以外のラベル → ❓

### 3. 日別データのシームレスな展開
- カレンダー上の日付（マス）をクリックすると、カレンダーのすぐ下に対象の日付のサイクルリストが展開されます。
- このリストは **全体表示（Flatモード）と全く同じUI** になっているため、これまで通り動画の再生や画像の拡大、詳細ページ（View Event Details）への遷移がスムーズに行えます。
- さらに、カレンダーはすべてブラウザ上のデータを使って一瞬で描画・切り替えを行うため、ページ遷移の待ち時間がなく非常にサクサク動作します。

## 確認のお願い
サーバーを再起動またはリロードし、以下の点をご確認ください。
1. 「表示形式」から「カレンダー (Calendar)」を選択できるか。
2. イベントが存在する日付のマスに、「〇件」および 🐾 や 👤 のアイコンが表示されているか。
3. 日付をクリックした際、その日の画像/動画データが下にズラッと一覧表示されるか。
4. カレンダー上部で「前月」「次月」への切り替えができるか。
