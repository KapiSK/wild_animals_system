# CCTデータセットを用いた V5a vs V6 評価計画

MegaDetectorの標準的な評価データセットである **Caltech Camera Traps (CCT) データセット** を用いて、V5a と V6 の性能を客観的な指標（Precision, Recall, F1スコア等）で評価するためのスクリプトを実装します。

## 目的
これまでの「V6を擬似正解とする」アプローチから一歩進み、**人間が作成した確実な正解（Ground Truth）ラベル**を用いて、両モデルの真の精度（過検出と取りこぼしの割合）を比較します。

## User Review Required
> [!IMPORTANT]
> 実装に入る前に、以下の点についてユーザーの状況をご確認させてください。
> 1. **データセットの準備状況**: CCTデータセット（画像フォルダと `*.json` のアノテーションファイル）は、検証用サーバー等にすでにダウンロード済みでしょうか？（未ダウンロードの場合、数十GB以上の容量が必要になります）
> 2. **評価の粒度**: 画像内に「動物が写っているか・いないか（Image-level）」の判定精度を比較できれば十分でしょうか？ それとも、バウンディングボックスの枠の位置まで正確かを測る「mAP（BBox-level）」の評価まで必要でしょうか？（Image-levelの方がシンプルかつ実用上の目的に近いです）

## Proposed Changes

### 評価用スクリプトの作成

#### [NEW] `ai_ex/evaluate_on_cct.py`
CCTのCOCOフォーマットのアノテーション（JSON）を読み込み、正解データと比較するスクリプトです。

1. **正解データ（Ground Truth）の読み込み**
   - CCTのJSONファイルをパースし、各画像に対する正解（Empty / Animal / Person）を抽出します。
   - CCTの種別（シカ、クマなど）はすべて「Animal（クラス0）」としてマッピングします。

2. **両モデルによる推論**
   - V5a および V6 を用いて、対象画像の推論を行います。

3. **精度評価メトリクスの計算**
   - `scikit-learn` を用いて、以下の指標を算出します。
     - **Accuracy (正解率)**
     - **Precision (適合率)**: AIが「動物がいる」と判定したうち、本当にいた割合（誤検知の少なさ）
     - **Recall (再現率)**: 実際に動物がいる画像のうち、AIが見つけられた割合（取りこぼしの少なさ）
     - **F1-Score**: PrecisionとRecallの調和平均
   - V5aとV6でそれぞれの数値を並べて比較（ターミナルへ出力）します。

4. **結果レポートの出力**
   - 誤分類した画像（例：正解はEmptyだがV5aが反応した、等）のリストを `cct_errors.csv` として出力し、原因分析に役立てます。
