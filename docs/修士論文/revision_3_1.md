## 本文差し替え案（LaTeX）

```latex
\section{トレイルカメラの概要}
\label{sec:background-trail-camera}

\subsection{トレイルカメラとは}
トレイルカメラは，野外に設置し，野生動物の姿や活動を自動的に記録するカメラである．
カメラトラップとも呼ばれ，人が常駐しない場所における野生動物の調査や監視に用いられる\cite{Beery2019,Welbourne2016}．
撮影画像に日時や設置場所を対応付けることで，動物の出現時刻や地点を確認できる．

動体検知を利用するトレイルカメラは，センサの反応を契機として撮影する．
この構成は，主に動体検知用のセンサ，撮影用のカメラ，制御回路，記憶媒体および電源からなる．
撮影した画像は記憶媒体に保存され，通信機能を備える構成では外部へ転送される．
本節では，本研究で扱うPIRセンサを用いた撮影の仕組みと，昼夜の撮影条件および画像の取得方法を説明する．

\subsection{PIRセンサによる動体検知}
\label{sec:background-capture}
PIR（Passive Infrared）センサは，対象や背景から入射する赤外線の変化を利用して動きを検知する受動型のセンサである．
トレイルカメラに用いられる焦電型のPIRセンサでは，フレネルレンズを介して入射する赤外線の変化を，焦電素子によって電気信号に変換する\cite{Welbourne2016,PanasonicPIR}．
対象が検知領域を横切ると，素子に入射する赤外放射が変化するため，その変化を動体検知に利用できる．
検知のしやすさは，対象表面と背景からの放射の違い，対象の移動方向および検知領域との位置関係に左右される．

トレイルカメラは，PIRセンサの出力を撮影開始のトリガーとして利用する．
この方式では，センサの反応に応じて撮影処理を開始できる．
ただし，PIRセンサは動物の形状や種を認識するものではなく，センサの反応だけで動物の存在を確定することはできない\cite{Welbourne2016}．
撮影画像に動物が含まれるかどうかの判定には，目視確認や画像認識による処理を用いる．

PIRセンサを用いる撮影では，動物が写っていない空撮影画像が生じる場合がある．
例えば，背景と異なる赤外放射を示す草木の揺れや，カメラ自体の揺れによる入射放射の変化が撮影の契機となる\cite{Welbourne2016}．
また，検知から撮影までの時間差や，センサの検知範囲とカメラの画角の違いによって，検知した対象が画像に写らない場合もある．
このため，センサの検知と，画像における動物の有無は区別して扱う．

\subsection{昼間・夜間の撮影}
トレイルカメラの撮影条件は，昼間と夜間で異なる．
昼間は周囲の光を利用して撮影できる一方，夜間など照度の低い環境では，補助照明を用いる構成がある．
赤外線照明を利用する場合，撮影用の照明は対象の像を得るために用いられ，撮影開始の契機を与えるPIRセンサとは役割が異なる．

撮影条件の違いは，画像内の動物の見え方に影響する．
昼夜では利用できる光が異なり，照明方式やカメラの設定によって，画像の明るさや色の情報も変化する．
さらに，対象までの距離，草木による遮蔽，動物の動きに伴うぶれは，画像から動物を確認する際の条件となる．
カメラトラップ画像の自動解析でも，夜間画像の扱いや背景を動物と判定する誤検出が課題として示されている\cite{Beery2019}．

\subsection{画像回収型と通信型}
トレイルカメラの運用は，利用者が画像を取得する方法に着目すると，画像回収型と通信型に分けられる．
画像回収型では，撮影画像をSDカードなどの記憶媒体に保存し，利用者が現地で回収する．
撮影地点に遠隔転送のための通信環境を必要としない一方，画像を確認できる時点は回収の時期に依存する．

通信型では，撮影画像や画像から得られる判定情報をネットワーク経由で遠隔地へ送信する．
現地で記憶媒体を回収せずに情報を取得できるが，通信経路と通信に必要な電力の確保が必要となる．
通信型でも画像を記憶媒体に保存する構成があるため，両者の違いは保存機能の有無ではなく，遠隔地へ情報を送る機能にある．

通信型のシステムでは，画像そのものを送る方式と，判定結果を中心に送る方式とで，遠隔地で利用できる情報が異なる．
画像を転送する方式では，利用者による目視確認やサーバでの再解析が可能となる．
一方，判定ラベルや撮影日時などを送る方式では，画像全体の送信を避けながら出現情報を伝えられる\cite{Whytock2023}．
したがって，通信型の構成を理解する際には，通信方式に加えて転送する情報の内容を確認する必要がある．
```
