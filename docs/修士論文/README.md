# 修士論文
題目：**獣害対策トレイルカメラシステムに関する研究**

2026年10月22日，提供された bthesis.zip と「修論の書き方」に合わせて移行しました。
main.pdf が現在の原稿です。本文の未確定箇所は灰色の記入案内として残しています。

## テンプレートと体裁
- jsbook，12pt，A4，片面，1カラム。slab.sty の mthesis オプションを使用します。
- テンプレートのロゴ，題目枠，修士論文表紙，余白，見出し，ヘッダーを使用します。
- frontmatter／mainmatter／backmatter により前付けと本文を分けます。
- 元テンプレートは template_original/ に保存しています。元ZIPも変更していません。
- 移行前の本文・PDF・設定は backup_before_bthesis_20261022.zip に保存しています。
- slab.sty は現行のビルド向けに画像・リンクのドライバをdvipdfmxへ統一し，日本語しおりをpxjahyperで処理します。未使用のtitleref依存を除き，booktabsとの定義衝突と表紙後のページ番号を調整しています。

## 章立て
1. 序論
2. 獣害対策における監視の課題
3. 前提知識
4. 関連研究
5. 提案システムの設計と実装
6. 提案システムの評価と考察
7. 結論

合意済みの前提知識の節構成は第3章へ移しています。旧「考察」章は第6章の節へ統合しています。
第2章は既存文献に基づく背景の文章を追加し，序論は段落の主張となる文から補っています。
第3〜5章は既存の本文を引き継ぎ，概要・評価結果・結論などの未完成部分には記入案内を残しています。
参考文献25件は初出順に整理しています。既存のthebibliographyを継続使用し，BibTeXは必須としていません。

## 編集
- metadata.tex：題目，提出年度・年月，所属，氏名，学籍番号，指導教員。未確認の個人情報は記入欄のままです。年度には「年度」を付けずに記入します。
- chapters/：各章の本文。第2章は02_research_background.tex，第3章は03_preliminaries.tex。
- frontmatter/abstract.tex：概要。
- backmatter/references.tex：参考文献。
- preamble.tex：図表の配置，パッケージ，共通命令。
- frontmatter/titlepage.tex は旧版の未使用ファイルです。現在の表紙はslab.styのmaketitleで生成します。

## 執筆要領の反映
「修論の書き方」を基準とします。
- 概要は1,000〜2,000文字。背景から結論までをまとめ，基礎知識は含めません。本文完成後に執筆します。
- 序論は背景〜提案を約9割，評価・結論を約1割とします。
- 一段落で一つの主張を扱い，トピックセンテンスを先に示します。
- 本文は現在形を基本とし，過去形の使用は結論に限ります。
- 結論は背景を約1割，提案と評価を約9割とし，新しい主張を追加しません。
- 図表は上詰め，1ページに合計2点まで。図キャプションは下，表は上です。既存図表はtp指定へ変更しています。半ページ程度という大きさの指示は資料上「卒論」の条件のため，修論では可読性と内容に合わせます。

## PDF生成
pLaTeXとdvipdfmxを使用します。以前のLuaLaTeX設定ではビルドしません。

リポジトリのルートから：
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "docs\修士論文\build.ps1"
```

3回コンパイルして参照を解決し，out/bthesis/main.pdf を main.pdf へコピーします。
ログは out/bthesis/ に保存します。latexmk用設定も同梱しています。
提出前にはメタデータと灰色の記入案内を確定し，図表の配置と参照を確認してください。

移行・執筆履歴は source_notes.md を参照してください。
