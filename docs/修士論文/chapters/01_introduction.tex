\chapter{序論}
\label{chap:introduction}
% 執筆要領：背景〜提案を約9割，評価・結論を約1割とし，基礎知識を繰り返さない．

\section{研究背景}
獣害対策の監視では，動物の出現状況を継続的に把握し，対策に必要な情報を利用者へ届けることが求められる．
\writehere{獣害対策における動物の出現状況把握の必要性と，トレイルカメラの役割を述べる．統計を用いる場合は対象年度と出典を明記する．}

\section{従来システムの課題}
複数地点での監視を継続するには，画像の回収と確認の負担に加え，通信と電源の制約を考慮する必要がある．
\writehere{現地での画像回収，空撮影画像の確認，通信費，消費電力などから，本研究が扱う課題を整理する．}

\section{研究目的}
本研究は，撮影専用カメラ，共有エッジサーバおよびクラウドを連携させ，動物画像の見逃しを考慮しながら広域通信へ転送する画像を選別するシステムを提案する．
\writehere{解決対象，想定する利用環境，達成目標，研究の対象外を明確にする．}

\section{本研究の貢献}
本研究では，複数カメラの画像集約と二段階の動物判定を組み合わせ，画像選別と通信・電源条件の関係を検討する．
\writehere{既存手法との差分と，本研究で設計・実装・評価した事項を，対応する根拠とともに整理する．}

\section{本論文の構成}
第\ref{chap:research-background}章では，獣害対策の監視における画像回収，通信および電源の課題を整理する．
第\ref{chap:background}章では，トレイルカメラ，画像認識，計算機および無線通信の前提知識を述べる．
第\ref{chap:related}章では，関連研究と本研究の位置付けを説明する．
第\ref{chap:system}章では，提案システムの構成と処理を述べる．
第\ref{chap:evaluation}章では，評価条件と結果を示し，その有効性と限界を考察する．
第\ref{chap:conclusion}章では，本研究をまとめ，今後の課題を述べる．
