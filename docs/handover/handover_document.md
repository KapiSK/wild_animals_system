# 引継ぎ資料：野生動物監視システムおよび論文執筆状況

本ドキュメントは、wild_animals プロジェクト（エッジカメラ・エッジサーバ・クラウドの連携システム）のアーキテクチャ概要、各ノードのハードウェア・ソフトウェア情報、およびICOIACT論文の執筆（修正）状況をまとめた引継ぎ資料です。

## 1. システムアーキテクチャとハード・ソフト情報

本システムは、現地での撮影からAI推論、クラウドでの集約・通知までを段階的に行う分散型アーキテクチャを採用しています。以下の4つの主要ノードで構成されています。

### 1.1 エッジカメラ (`esp`)

* **ソースパス**: `esp/` (および `dual_cpu_project/esp/`)
* **役割**: 現地で野生動物などを撮影し、画像データをエッジサーバーへ送信するセンサーノード。
* **ハードウェア**: ESP32ベースの自作プロトタイプカメラ。
* **ソフトウェア**: カメラ制御およびWi-Fi通信プログラム。待機時の消費電力が課題となっており、ディープスリープ最適化やモジュールの電源制御等が検討されています。

### 1.2 エッジサーバー (`pi`)

* **ソースパス**: `pi/`
* **役割**: ESP32からの画像をローカルネットワーク内で受信し、一次処理を行う中間ノード。
* **ハードウェア**: Raspberry Pi などのシングルボードコンピュータ。
* **ソフトウェア**: YOLO等のエッジAIモデルを用いた推論スクリプト。動物や人間の検出結果に基づいて、該当画像のみをクラウドサーバーへ転送し、通信量を削減します。

### 1.3 統合サーバー (`satos`)

* **ソースパス**: `satos/`
* **役割**: 自作カメラ（ESP32）以外の既製品カメラ（トレイルカメラ等）から送信されるデータを統合処理するノード。
* **ハードウェア**: サーバー・PCデバイス。
* **ソフトウェア**: 指定のGmailアカウントに送られてきた動画を定期的にポーリング取得し、フレーム抽出や推論の一次処理を行った上で、クラウドサーバーへ転送する自動化スクリプト。

### 1.4 クラウドサーバー (`original_server`)

* **ソースパス**: `original_server/`
* **役割**: 全てのエッジ（pi）および統合（satos）サーバーからのアップロードデータを集約・統合管理するメインノード。
* **ハードウェア**: クラウドサーバー。
* **ソフトウェア**: FastAPIを用いたAPIサーバー。最終的なデータ分析、画像の結合処理、およびシステム管理者宛のメール通知（アラート送信）などを担当します。エッジ側のパース仕様（ファイル命名等）との整合性維持が重要です。

## 2. ICOIACT 論文執筆・修正状況

現在、ICOIACTに採択された論文のカメラレディ版作成に向けて、査読者からのコメントに対する修正計画を策定済みの段階です。

* **修正計画**: `docs/icoiact_paper_revision/implementation_plan.md`
* **論文原稿 (TeX)**: `docs/ieice_paper_draft/icoiact_draft/main_english.tex` (著者情報入りは `main_english_with_authors.tex`)

### 主な査読指摘事項と対応方針

1. **実験設定とデータセットの明確化**
   * 対象となる野生動物（イノシシ、シカ等）の明記。
   * エッジ評価実験で使用した画像（木曽のデータ）が、本プロトタイプで撮影されたものではなく、既存カメラによる事前収集データであることを明記。
2. **YOLO分類器の限界と誤分類の考察**
   * 正解例、誤検知例、見逃し例（夜間の不鮮明画像等）を示すサンプル画像の追加。
   * なぜ誤分類が発生したかの詳細な考察（Discussion）の追加。
3. **評価手法と実用上の課題への言及**
   * MegaDetectorによる疑似正解ラベル（Pseudo-ground truth）を利用したことによる科学的限界（Limitation）への言及。
   * 野外通信テストが限定的環境で行われたことや、見通しの良い場所（100m以内）での利用を推奨する実用的な展開ガイドラインの追加。
4. **消費電力と夜間精度の向上策の提示**
   * **消費電力**: コンポーネントへの給電遮断（MOSFET等）やESP32のディープスリープ最適化などの具体的解決策の提示。
   * **夜間精度**: 夜間画像を用いた転移学習や低照度特化モデルの導入検討の議論追加。
5. **その他改善点**
   * 既存システムとの比較表（Table）の追加。
   * Future Work の具体化（独自基板開発、LoRaWAN検証など、実行可能なタスクへの書き換え）。
   * IEEEtranの規定に合わせた図表フォーマットの修正。

今後の主なタスクは、上記の実装計画に基づき、`uplatex` 環境での TeX 原稿の加筆・修正およびビルドによる最終確認となります。
