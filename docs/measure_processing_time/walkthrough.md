# 変更内容の確認 (Walkthrough): エッジサーバー処理時間の計測

エッジサーバーの処理時間を詳細に計測するための変更を行いました。

## 変更されたファイル

### `pi/main.py`

処理時間の計測とログ出力ロジックを追加しました。

#### 主な変更点

1. **計測タイマーの追加**:
    * `time.perf_counter()` を使用して、以下の処理時間をミリ秒単位で計測します。
        * **Save**: 画像受信からディスク保存完了まで。
        * **Inference**: 物体検出（YOLO）の実行時間。
        * **Forward**: 条件を満たした場合の外部サーバーへの転送時間。
    * `CycleManager` にて、サイクル開始（1枚目受信）から終了（3枚目処理完了）までの合計時間を計算します。

2. **ログ出力**:
    * `[PERF]` タグ付きのログを出力するようにしました。これにより、ログファイルから簡単にパフォーマンスデータを抽出できます。

    **ログ出力例:**

    ```text
    [PERF] Cycle MAC-SEQUENCE Finished. Total Time: 1542.30ms
    [PERF] Breakdown: Save=320.10ms, Inference=850.50ms, Forward=200.00ms
    ```

### `pi/verify_perf.py`

パフォーマンス計測を検証するためのスクリプトを作成しました。
このスクリプトは、3枚のテスト画像を連続してサーバーに送信し、1サイクルを完了させます。

## 検証手順

ユーザー側で検証を行う場合は、以下の手順を実行してください。

1. **サーバーの起動**:

    ```bash
    cd pi
    python -m uvicorn main:app --port 8000
    ```

2. **検証スクリプトの実行**:
    別のターミナルで以下を実行します。

    ```bash
    cd pi
    python verify_perf.py
    ```

    ※ `test.jpg` が `pi` ディレクトリ内に存在することを確認してください。

3. **ログの確認**:
    `pi/edge_server.log` または標準出力を確認し、`[PERF]` で始まる行が出力されていることを確認します。
