# 修正内容の解説・確認手順 (RSSI Mapper)

既存のトレイルカメラプロジェクトとは完全に独立した新規プロジェクトとして、エッジカメラを用いたWi-FiのRSSI測定と風景記録を行うプログラムを作成しました。

## 実装内容
- **ファイル作成**: `dual_cpu_project/esp/rssi_mapper/rssi_mapper.ino` を新規作成しました。
- **機能概要**:
  - 起動時にWi-Fiに接続し、SDカードとカメラを初期化します。
  - 1秒間隔でWi-FiのRSSI（電波強度）を取得します。
  - 前回の記録時からRSSIが **5dBm以上** 変化した場合、現在の風景を撮影します。
  - 撮影した画像をSDカードの `/rssi_map/` フォルダに `img_タイムスタンプ_R[RSSI].jpg` というファイル名で保存します。
  - 同時に、`/rssi_map/rssi_log.csv` にタイムスタンプ、RSSI値、ファイル名を記録します。
- **LEDによる通知機能**:
  - **記録成功時**: フラッシュ用LED（`GPIO 6`）が0.2秒間点灯し、撮影・記録が成功したことを通知します。
  - **エラー発生時**: カメラ初期化やSDカードマウントに失敗した場合、LEDが高速で連続点滅し、異常を通知します。
- **BLEリアルタイム通知機能 (New!)**:
  - Wi-FiのRSSI、切断状況、撮影ステータスなどをBluetooth経由でスマホへ送信します。

## 確認手順 (Manual Verification)

### 基本動作の確認
1. **書き込み**: 作成した `esp/rssi_mapper/rssi_mapper.ino` をESP32に書き込んでください。
2. **実行・移動**: ルーター等のアクセスポイントに接続できる範囲で電源を入れます。LEDのエラー点滅が起きないことを確認し、カメラを持って移動してください。
3. **通知の確認**: 移動によってWi-Fiの電波強度が変化すると、しきい値（3dBm等）を超えたタイミングでLEDが一瞬点灯します。
4. **データの確認**: テスト終了後、SDカードをPC等で読み込み、指定のディレクトリ内に画像とCSVログが作成されているか確認してください。

### BLEリアルタイム通知の確認
1. スマホに「LightBlue」などのBLEスキャンアプリをインストールします。
2. アプリを開き、周囲のデバイス一覧から `ESP-RSSI` を見つけて接続（Connect）します。
3. 接続後、サービス（`4fafc201...`）内にあるキャラクタリスティック（`beb5483e...`）をタップします。
4. 画面内の `Listen for notifications` (または `Subscribe`) ボタンを有効にします。
5. ESP32から1秒ごとに `[OK] RSSI: -65 dBm` などの通知が画面に流れることを確認します。
6. Wi-Fi圏外に出た際に `[ERR] WiFi Disconnected` と表示されることや、撮影が行われた際に `[REC] Saved!` と表示されることを確認してください。
