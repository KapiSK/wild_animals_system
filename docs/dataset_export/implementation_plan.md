# データセット（画像＋BB）一括ダウンロード機能の実装計画

AIの再学習や詳細なオフライン分析（Timelapse等のツール）に活用できるよう、画像と推論結果（Bounding Boxとラベル）をまとめてダウンロードできる機能を実装します。

## 背景と要件
- ユーザーは、AI推論で得られたBounding Box (BB) とラベルを含むメタデータと、それに対応する画像データを一括ダウンロードしたい。
- クラウドサーバの推論モデルは **MegaDetector (MD)** を使用しているため、エクスポート形式もMDエコシステムに合わせたフォーマットとする。
- Web上（ブラウザ）から、**カメラ、期間、対象ラベル（空画像含む）、確信度**でデータを緻密に絞り込んでダウンロードできるようにする。
- サーバー負荷やタイムアウトを防ぐための安全装置を設け、上限を超えた場合は**「条件を絞り込む」か「分割してすべてダウンロードする」かをユーザーが選べる**ようにする。

## 💡 実装方針（MegaDetectorフォーマット ＋ カスタム抽出）

### 1. 推論時のBB座標の保存（バックエンド改修）
`server.py` の `analyze_image_for_cycle` 関数を改修し、推論結果から以下の情報を抽出・保存します。
- `[xmin, ymin, width, height]` （画像サイズに対する0.0〜1.0の正規化値）
- `category_id`, `confidence`
- これらのデータを `event_metadata` にリストとして追加し JSON 保存します。

### 2. UIの追加 (フロントエンド・Web上の選択機能)
統計画面の上部に「📦 Export Dataset」ボタンを設置し、クリックすると**ダウンロード設定モーダル**が開くようにします。
- **事前件数確認機能 (案1 + 案3の統合)**: 
  - フィルタ条件（カメラ、期間、ラベル、確信度）を指定してバックエンドに総件数を問い合わせます。
  - **1,000件以下の場合**: そのまま「Download ZIP」ボタンを表示。
  - **1,000件を超える場合**: 「⚠️ 上限(1,000件)を超えました。条件を絞り込むか、以下の分割ダウンロードをご利用ください」と表示。
  - その下に、`[Download Part 1 (1-1000)]`, `[Download Part 2 (1001-2000)]`... のように**分割ダウンロード用のボタン**を動的に生成します。

### 3. データエクスポートAPIの作成 (`/api/export`)
- **プレビュー用 (`/api/export/preview`)**: フィルタ条件を受け取り、合致する総件数と処理対象のメタデータIDリストを返します。
- **ダウンロード用 (`/api/export/download`)**: フィルタ条件に加え、`page` を受け取ります。
  1. 該当する `metadata_*.json` を走査し、指定ページ分（最大1,000件）のデータを抽出。
  2. 抽出した情報を1つの **MegaDetector 結果 JSON (`md_results.json`)** にフォーマット。
  3. **過去データの互換性 (Backward Compatibility)**: BB情報が記録されていない過去のメタデータについては、エラーを出さずに「BB情報なし（アノテーション空）」としてJSONに記録し、画像ファイル自体は通常通り ZIP 内に含めてダウンロードさせます。
  4. `md_results.json` と画像ファイル群を `dataset_partX.zip` として圧縮して返却します。
