# データセット一括ダウンロード機能 実装ウォークスルー

AIの再学習やオフライン解析を強力に支援する、**MegaDetector互換のデータセット（画像＋Bounding Box）一括ダウンロード機能**を実装しました。

## 💡 主要な変更点

### 1. 推論結果（BB座標）の保存機能
`server.py` の推論ロジック (`analyze_image_for_cycle`) を拡張しました。
- 画像に対するYOLO推論結果から、MegaDetectorの標準的なフォーマットである **正規化座標（`[xmin, ymin, width, height]`）** を抽出し、各画像の `detections` 配列としてメタデータ（`event_metadata`）に永続化されるようになりました。

### 2. データエクスポートAPI (`/api/export`) の構築
安全かつスケーラブルなデータエクスポートのためのAPIを新設しました。
- **`/api/export/preview` (プレビューAPI)**
  - 指定されたフィルタ条件（カメラ、期間、ラベル、確信度、空画像有無）に基づいてメタデータを走査し、「条件に合致する画像の総件数」を高速に返します。
- **`/api/export/download` (ダウンロードAPI)**
  - ページネーション（1ページ＝最大1000件）を実装し、サーバダウンを防ぐ**安全装置（ハードリミット）**として機能します。
  - バックグラウンドで画像ファイル群と、`md_results.json` (MegaDetector互換のCOCO Camera Traps JSONフォーマット) をひとつのZIPに圧縮してダウンロードさせます。
  - 過去に推論された「BB情報がない古いデータ」にも安全にフォールバック（アノテーション空の画像として処理）するように互換性を確保しています。

### 3. モーダルUIの追加 (フロントエンド)
統計画面 (`/statistics`) からワンクリックでアクセスできる、モダンな**エクスポート用モーダル画面**を実装しました。

- **フィルタ機能**: 特定のカメラ、カレンダーでの期間指定、出力したい対象ラベルのチェック（AIの再学習に必要な**Empty / No Detection (空画像)**も含む）、確信度の範囲（Min/Max）指定が可能です。
- **件数確認（事前プレビュー）**: 「Check Data Size」を押すことで、ダウンロード前に何枚の画像が含まれるかを確認できます。
- **スマートな分割ダウンロード（ハイブリッドアプローチ）**: 該当件数が上限（1000枚）を超えた場合、**「条件を絞り込む」**か、**「複数のZIP（Part 1, Part 2...）に分割してすべてダウンロードする」**かをユーザーが選べる動的なボタンUIを構築しました。

## 🔍 確認手順 (Verification)

1. Webブラウザでシステムのトップ画面から **[📊 Statistics]** を開きます。
2. 画面上部に追加された **[📦 Export Dataset]** ボタンをクリックします。
3. モーダル内で、カメラ、ラベル（Emptyを含む）、確信度などの条件を自由に変更し、**[Check Data Size]** ボタンを押します。
4. 該当件数が表示されます。もし件数が多い場合は、分割された `Download Part X` ボタンが生成されるので、それをクリックしてZIPをダウンロードします。
5. ダウンロードしたZIPファイルを解凍し、中に「生画像データ」と「`md_results.json`」が含まれていることを確認してください。

以上で、再学習用のデータ収集機能が完全に統合されました！
