# 実装計画: ESP32 エラー修正 (ポート不一致 & カメラ不安定)

## 問題の分析

ユーザーから提供されたログに基づき、以下の2つの問題が判明しました。

1. **Piサーバー接続エラー (`HTTP -1`)**
    * ESP32はポート **5000** に接続しようとしていますが、サーバー (`server.py`) はポート **8000** で起動しています。
    * これが接続拒否 (`HTTP -1`) の原因です。

2. **カメラ撮影エラー (`Capture failed`)**
    * `esp_camera_fb_get()` が失敗しています。
    * 現在の設定 `fb_count = 1` と `grab_mode = CAMERA_GRAB_LATEST` の組み合わせが、タイミングによってバッファ取得失敗を引き起こしている可能性があります。XIAO ESP32S3 Sense はPSRAMがありメモリに余裕があるため、バッファ数を増やすことで安定化を図ります。

## 修正内容

### `esp/camera/camera.ino`

1. **ポート番号の修正**
    * `mDNS` 解決後のURL生成部分で、ポートを `5000` から `8000` に変更します。

2. **カメラ設定の変更 (`initCamera`)**
    * `config.fb_count` を `1` から `2` に変更します。
    * バッファを複数持つことで、撮影の取りこぼしを防ぎます。

## 検証計画

* 修正後のコードをコンパイルし、ユーザーに再度動作確認 (ログの確認) を依頼します。
* 期待される結果:
  * `[UPLOAD] Pi server OK` となり、アップロードが試行されること。
  * `[ERR] Camera capture failed` が消え、画像が保存されること。
