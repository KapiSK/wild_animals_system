# 統計ダッシュボード機能の実装計画

保存された検知データ(`statistics.csv`)を可視化する新しい統計画面 (`/statistics`) を実装し、一覧画面からアクセスできるようにします。

## 背景と要件
- ユーザーから提案された構成案（KPIカード、時間帯ヒートマップ、検知数・気温の推移グラフ等）をもとに実装する。
- ギャラリーページ等から容易にアクセスできるよう遷移ボタンを適切に配置する。

## Proposed Changes

### 1. `server.py` バックエンドAPIの追加
- **[NEW] `/api/statistics` (GET)**: 
  - `statistics.csv` を読み込み、JSON形式のリストとして返すエンドポイントを作成します。

### 2. 統計ダッシュボード画面の追加
- **[NEW] `/statistics` (GET)**: 
  - HTMLとCSS、JavaScript（Chart.js）を含むフロントエンドを返すエンドポイントを作成します。
  - **デザイン**: 既存ページと同様のGlassmorphism・ダークモード対応（`data-theme="dark"`とトグルボタン）を実装します。
  - **グラフ構成**:
    1. **Overview**: 総検知数、直近の検知数などの主要数値をカード表示。
    2. **時間帯分析 (Time Activity)**: 0時〜23時の時間帯別検知数を棒グラフで表示。
    3. **日別推移・気温相関 (Daily Trends)**: 日付ごとの検知数を積み上げ棒グラフで表示し、同グラフ内にその日の平均気温を折れ線グラフで重ね合わせます。
    4. **カメラ別・動物別分析 (Distribution)**: カメラ別、動物別の割合をドーナツグラフ等で可視化します。

### 3. 画面間遷移ボタンの配置
- **[MODIFY] `server.py` の Gallery 画面**:
  - `html_content` 内の `<div class="top-actions">` に「📊 Statistics」ボタンを追加し、統計ページへ遷移できるようにします。
- **[MODIFY] 統計画面**:
  - 画面上部に「← Back to Gallery」ボタンを配置します。

## User Review Required

> [!IMPORTANT]
> 1. この統計画面は、管理者以外の「一般閲覧ユーザ（role=user）」も閲覧できる仕様でよろしいでしょうか？（提案では全員が閲覧可能とします）
> 2. `statistics.csv` 内の `labels` （動物名）について、グラフ上の凡例などでは英語のまま（例: "person", "dog"）表示する想定ですが問題ないでしょうか？

## Verification Plan

### Manual Verification
- ローカル環境でサーバを起動し、`/gallery` の上部に遷移ボタンが表示されているか確認します。
- ボタンをクリックして `/statistics` に遷移し、UIが正しく表示されるか確認します。
- `statistics.csv` にダミーデータを作成して配置し、各グラフ（推移、時間帯、割合等）が正しく描画・連動するかを確認します。
- 右下のトグルボタンでライト/ダークモードが正しく切り替わるか確認します。
