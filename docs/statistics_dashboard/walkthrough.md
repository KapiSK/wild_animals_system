# 統計ダッシュボードの実装完了

野生動物の検知データ（`statistics.csv`）を可視化する、リッチな統計ダッシュボード画面 (`/statistics`) を実装しました。

## 変更内容のサマリー

1. **データ取得APIの追加 (`/api/statistics`)**:
   - `statistics.csv` を読み込み、フロントエンド向けにJSON形式でデータを配信する専用エンドポイントを追加しました。

2. **統計ダッシュボード画面の追加 (`/statistics`)**:
   - Chart.js を用いて、データの傾向を分析するための3つの主要なグラフと、KPIサマリーを実装しました。
   - **グラフ構成**:
     - **Overview Cards**: 総検知数、アクティブなカメラ数、最も検知された動物を数値で表示。
     - **Daily Trends & Temperature**: 日別の検知数を棒グラフで表示し、その日の平均気温を折れ線グラフで重ねて表示（相関関係の分析）。
     - **Activity by Hour**: 0時〜23時の時間帯別に出現傾向を棒グラフで表示（夜行性の分析等）。
     - **Distribution by Animal**: 検出された動物の割合をドーナツグラフで表示。
   - **デザイン**: 既存の画面（Gallery等）と統一感を持たせた Glassmorphism と、右下のボタンによるダークモード/ライトモードの動的切り替えに対応しています。グラフの文字色やグリッド色もモードに合わせて自動で変化します。

3. **画面遷移の追加**:
   - ギャラリー画面（`/gallery`）の上部アクションエリアに、`📊 Statistics` ボタンを追加し、1クリックでダッシュボードに遷移できるようにしました。
   - 統計画面の左上には `← Back to Gallery` ボタンを配置し、往復のナビゲーションをスムーズにしました。

## 確認方法
1. カメラから画像が数回アップロードされ、`statistics.csv` にデータが蓄積されている状態にします。
2. ブラウザで `/gallery` にアクセスし、右上の `📊 Statistics` ボタンをクリックします。
3. リッチなグラフが描画され、ダークモードを切り替えた際にグラフのスタイルも追従することを確認します。
